# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs).

An ADR is a short document that records an important architectural or technical decision, including the context behind it, the decision that was made, and its consequences.

ADRs help future maintainers understand not only **what** was decided, but also **why**.

Typical topics include:
- Architecture and module boundaries.
- Technology or dependency choices.
- API and data-model decisions.
- Important implementation constraints.
- Decisions that may be difficult or costly to reverse.

Each significant decision should normally have its own ADR file.
